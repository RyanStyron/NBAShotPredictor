# Predicting NBA Shot Outcomes
This repository contains the code, data pipelines, and experimental results for predicting binary NBA shot outcomes (Make/Miss) across two decades of basketball data (2004–2024).

By stripping away specific player identities and replacing them with generalized biometrics (height, weight, age), this project explores predicting highly stochastic physical events. Furthermore, it conducts a temporal analysis to determine if modern basketball has rendered older data obsolete.
